Modelo LightGBM entrenado con licitaciones publicadas entre abril y junio de 2026. En datos que no vio al entrenar, el 10% de licitaciones que marca como más riesgosas quedó desierta el 40% de las veces, el doble que el promedio. Es una estimación para priorizar revisiones, no una garantía. El código y la metodología están en GitHub, y la API está documentada.
