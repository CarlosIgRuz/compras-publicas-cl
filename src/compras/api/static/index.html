    Una desierta no siempre significa falta de interés: en el 69% de los casos hubo ofertas que no cumplieron las bases. Revisa los requisitos antes de postular.

    Modelo LightGBM entrenado con licitaciones publicadas entre abril y junio de 2026. En datos que no vio al entrenar, el 10% de licitaciones que marca como más riesgosas quedó desierta el 40% de las veces, el doble que el promedio. Es una estimación para priorizar revisiones, no una garantía. El modelo corre en tu navegador: los datos que ingresas no se envían a ningún servidor. El código, la metodología y la API están en GitHub.
